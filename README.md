# Korero

Conversations do not end when a message is read. Someone needs to reply,
follow up, or get something done. Kōrero connects the conversation to that work.

Our aim is the familiarity of an email client with a task runner underneath:
one place to talk, act, and follow through. Keep the discussion close to the
work it creates, so the next step has a clear place to live.

*Kōrero* is Māori for talk, discussion, conversation, or story.

This is an early library foundation, not a finished email client. It uses Ash
and Oban; applications bring their own interface and workflows.

Install the experimental Git alpha:

```elixir
{:korero, github: "vintrepid/korero", tag: "v0.1.0-alpha.2"}
```

Korero is also available through AshLotus. See the
[integration guide](docs/integration.md) for setup, capabilities, and current
limitations.

Pre-1.0 APIs may change.
